# Architecture Decision Records

Architecture Decision Records (ADRs) capture decisions that materially affect
the structure, runtime behavior, packaging, or long-term maintainability of
Steam Recording Browser.

## Status values

- Proposed
- Accepted
- Superseded
- Deprecated
