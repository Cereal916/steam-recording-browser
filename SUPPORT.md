# Support

## Getting help

Before opening an issue:

1. Confirm you are using the latest release.
2. Review the troubleshooting section in the [README](README.md#troubleshooting).
3. Search [existing issues](https://github.com/Cereal916/steam-recording-browser/issues).

If the problem remains, open a
[bug report](https://github.com/Cereal916/steam-recording-browser/issues/new/choose)
with the application version, Windows version, reproduction steps, and only the
relevant portions of the application log.

Logs and screenshots may contain game names, recording names, or local file
paths. Review and redact them before posting publicly.

## Feature requests

Use the repository's feature-request form and describe the problem or workflow
the feature would improve.

## Security issues

Do not report vulnerabilities in a public issue. Follow the private reporting
instructions in [SECURITY.md](SECURITY.md).
